# Handoff — 2026-09-05

## Goal
Audit the TexasInvestors dashboard, find why it felt "useless," and close
the real gap: no automated property valuation or comps, and no way to
look up a single address on demand. Build a RentCast connector, an HCAD
per-address lookup, and a database to save each lookup incrementally.

## Current state
The app runs at `http://127.0.0.1:8765` (`.venv\Scripts\python.exe app.py`)
with 100 real Harris County leads, HCAD facts joined in, and a working
**"Look up market data"** button on every property that calls RentCast +
HCAD live and saves the result. Confirmed working end to end today,
including a real RentCast call returning a value estimate and 15 comps.

Everything in the working tree is now committed to git on `main`
(commit `cc28dac`) and pushed to `origin` — including a large backlog of
application files (dashboard frontend, scoring, underwriting, buyer
matching, scripts, tests, docs) that existed on disk but had never been
committed before this session. If anything looks unfamiliar in the diff,
it's prior work being captured for the first time, not new today.

- **`app.py`** — new `POST /api/lookup` endpoint; leads now carry a
  `market_lookup` field read from the database.

## Decisions made
- **HCAD live path is ArcGIS, not Playwright.** `search.hcad.org` is
  Cloudflare-gated on every request (confirmed live, including its own
  robots.txt). That's the same class of anti-bot mechanism the codebase
  already declines to script past for the tax-delinquent CAPTCHA. HCAD's
  own public GIS map calls a plain REST endpoint with no such gate —
  lighter and more reliable than a browser script would have been.
- **RentCast estimates stay separate from underwriting.** The AVM number
  is not written into the manually-entered ARV/repairs fields — those
  are meant to be your own reviewed numbers, not an automated guess.
- **Everything on disk got committed.** Rather than leave a large,
  undocumented gap between the working app and git history, the whole
  working tree (minus what `.gitignore` already excludes — the database,
  bulk HCAD downloads, generated output, `.venv`) was committed as-is.

## Known gaps / risks
- **RentCast free tier: 50 requests/month.** Each button click spends one.
  There's no in-app quota counter — track usage on RentCast's dashboard.
- **HCAD coverage is Harris County only**, same as before. The other
  seven counties in scope (Fort Bend, Montgomery, Brazoria, Galveston,
  Waller, Liberty, Chambers, Nacogdoches) still have no automated source.
- **`RENTCAST_API_KEY` must be set in every terminal that starts `app.py`**,
  or saved permanently via `setx` (takes effect in new terminals only,
  not ones already open).
- **No CI.** Tests and browser QA are run manually; nothing runs them
  automatically on push.
- The root-level `Texas Investors lead dashboard.zip` and `picturedforapp/`
  images are early design references, not part of the running app —
  committed for safekeeping, not because code depends on them.
